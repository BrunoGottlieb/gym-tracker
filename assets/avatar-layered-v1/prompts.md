# Layered avatar prototype

Generated with the built-in image generator, using the approved “04 · Miniatura suave” mockup as a reference. Transparent PNGs are kept unchanged in `public/avatars/layered-v1/`; layout and alignment are applied in CSS. This prototype is a visual comparison only and does not change a saved avatar, levels or workout data.

## base.png

Use case: precise-object-edit / modular avatar game asset.
REFERENCE AND STYLE TARGET: the supplied mockup image, specifically the large central soft 3D miniature athlete. The user explicitly chose that exact character aesthetic, not a simplified procedural sphere doll.
Create a production-quality BASE LAYER of that same full-body miniature, isolated on a genuinely transparent background. It should closely match the mockup: friendly young adult male toy character, oversized rounded head, short compact rounded body, warm peach skin, dark oval eyes, tiny friendly smile and subtle nose, blue athletic tank top, navy tailored soft shorts with narrow white side piping, chunky white sneakers. Same high quality soft clay/plastic 3D render, sculpted smooth details, gentle studio illumination from upper left, subtle soft ambient occlusion, rich restrained cobalt clothing and attractive rounded proportions.
CHANGE ONLY for modularity: make the character completely BALD (smooth natural scalp), remove visor, remove wristbands, remove all hair and headwear. No accessory anywhere. Keep hands on hips as in the mockup, identical face appeal, legs slightly apart, feet fully visible. Frontal view with only a very slight three-quarter turn, and no rotation between limbs. Preserve the original large head, wide cute torso, and refined 3D clothes; do not convert him to flat vector or crude geometric humanoid.
Composition: ONE character only in a square 1024 x 1024 transparent canvas. Entire body centered at x512. Leave generous empty transparent headroom for future hair layers (about 12% of image height) and 6% margin below shoes. No UI, no panels, no labels, no letters, no background rectangle, no checkerboard pattern, no secondary characters, no giant cast shadow, no ground or pedestal. Alpha transparency around silhouette and inside limb gaps.
